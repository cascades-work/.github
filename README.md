# Cascades

Cascades is an orchestration platform for data, AI, infrastructure, and event-driven workflows.

Build, schedule, and operate workflows through a declarative model with visual authoring, event-driven execution, extensible plugins, and infrastructure-friendly deployment.

## Start here

- [Cascades](https://github.com/cascades-work/cascades) — core orchestration platform
- [Website](https://cascades.work)
- [Documentation](https://cascades.work/docs)
- [Releases](https://github.com/cascades-work/cascades/releases)

## Ecosystem

The Cascades organization contains the core platform, plugins, SDKs, integrations, and deployment tooling that make up the Cascades ecosystem.
