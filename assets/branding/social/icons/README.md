# Social brand icons

Monochrome variants of official platform marks, normalized to a single
`#101316` fill for use on light backgrounds (READMEs, docs, profile pages).

| Icon | Source |
|------|--------|
| `bluesky.svg` | Bluesky brand mark via [simple-icons](https://github.com/simple-icons/simple-icons) (`icons/bluesky.svg`) |
| `discord.svg` | Discord brand mark via [simple-icons](https://github.com/simple-icons/simple-icons) (`icons/discord.svg`) |
| `youtube.svg` | YouTube brand mark via [simple-icons](https://github.com/simple-icons/simple-icons) (`icons/youtube.svg`) |
| `linkedin.svg` | LinkedIn "in" glyph from the official mark on [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:LinkedIn_icon.svg) |

Each platform permits monochrome treatment under its brand guidelines. Keep
icons visually consistent: render at a single height (e.g. 20px), equal spacing,
baseline-aligned.
