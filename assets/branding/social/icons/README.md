# Social brand icons

Monochrome glyphs used for social callouts across Cascades READMEs, profile
pages, and documentation. All four are normalized to a single `#101316` fill
for use on light backgrounds, and should be rendered at a consistent size
(e.g. 20px) with equal spacing and baseline alignment.
